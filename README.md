# 🌍 Global Translator Pro MAX — Language Super App

**Version:** Pro MAX | **Status:** Live | **Developer:** N4YEEM

**Global Translator Pro MAX** is an all-in-one, browser-based language companion designed to break language barriers worldwide. Built with a focus on speed, privacy, and usability, it combines multi-language translation, OCR, PDF text extraction, a smart dictionary, and an offline vocabulary builder into a single lightweight web application.

**Live Demo:** https://world-translator-pro-lite.netlify.app/ *(Update link if hosted on a new URL)*

---

## ✨ Key Features

### 🌐 Smart Multi-Language Translator
* **20+ Languages Supported:** Translate seamlessly between English, Bengali, Arabic, Hindi, Spanish, French, German, Japanese, Chinese, Korean, Russian, Portuguese, Italian, Turkish, Thai, Urdu, Indonesian, Vietnamese, Persian, and Malay.
* **Auto-Detect & Real-Time Translation:** Automatically detects source language and translates as you type.
* **Voice & Audio Tools:** Built-in Speech-to-Text (`🎤 Voice`) input and Text-to-Speech (`🔊 Listen`) pronunciation.
* **Quick Actions:** One-click copy, share, font size adjustment (`A-` / `A+`), and Dark/Light theme toggle (`🌙`).

### 🖼 Image & PDF Translator (Client-Side)
* **Image to Text (OCR):** Extract text directly from images supporting **English**, **বাংলা (Bengali)**, or **English + বাংলা** combined.
* **PDF to Text:** Extract text from text-based PDF documents and send it straight to the translator.
* **100% Privacy-Focused:** All OCR and PDF processing happens directly inside your browser—no files are uploaded to external servers.

### 📖 Smart Dictionary
* Look up English word definitions, phonetics/pronunciation, synonyms, and real-world usage examples instantly.

### 🎓 Daily Language Learning (Offline Ready)
* **Word of the Day:** Learn useful English vocabulary with audio pronunciation.
* **Interactive Quiz:** Test your vocabulary knowledge with built-in quizzes that work completely offline once the page loads.

### 🗂 Data Management & Backup
* **History & Favorites:** Keep track of recent translations and bookmark important ones (`⭐ Saved`).
* **Export & Restore:** Easily back up your translation history as a file and restore it anytime across devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **OCR Engine:** Client-side OCR processing (e.g., Tesseract.js)
* **PDF Parser:** Client-side PDF text extraction (e.g., PDF.js)
* **Storage:** Browser `localStorage` with JSON Export/Restore support
* **Hosting:** Netlify
