# 🌐 Global Translator Pro

A fast, lightweight real-time web translator supporting 20+ languages with auto-detection, voice input, text-to-speech, and dark mode.

🔗 **Live Demo:** [world-translator-pro-lite.netlify.app/](https://netlify.app)

## ✨ Key Features
* **Auto-Detect Language:** Automatically detects the source language as you type.
* **20+ Languages:** Supports Bengali, English, Hindi, Arabic, Spanish, French, and many more.
* **Voice Input & Listen:** Speak to translate and listen to the pronunciation of translated text.
* **Translation History:** Automatically saves recent translations locally for quick access.
* **Dark Mode:** Eye-friendly dark theme toggle for comfortable night use.

## 🛠️ Built With
* **HTML5**
* **CSS3**
* **JavaScript**
